# Tasks: Prompt Runner

**Input**: Design documents from `/specs/001-simple-prompt-runner/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md), [data-model.md](data-model.md), [contracts/](contracts/), [quickstart.md](quickstart.md)

**Tests**: Included. The plan's test strategy ([research R10](research.md)) and the relay contract tests ([contracts/relay-api.md](contracts/relay-api.md)) require them, and constitution Principle V asks for verifiable requirements. Within each story, write the tests first and see them fail before implementing.

**Organization**: Tasks are grouped by user story. Stories 1–4 each build one section of the page and can be tested on their own (each has an end-to-end scenario); story 5 (run and report) is where the value is delivered and uses what stories 1–4 provide; stories 6 and 7 extend it.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: User story from [spec.md](spec.md) (US1–US7)
- Paths are relative to the repository root

## Path Conventions

Static page under `app/public/` (modules in `app/public/src/`, views in `app/public/src/ui/`), relay under `app/`, tests under `tests/` (`unit/`, `contract/`, `e2e/`, `fixtures/`, `live/` already exists). No third-party dependencies, no build step (plan: Technical Context).

**Language rule (spec FR-036)**: every user-visible text (labels, buttons, hints, messages, report) is in English, including the start button "New Session"; the ready-made judge prompts are in English.
